# think

A collection of Claude Code skills for structured, powerful thinking.

## Skills

### elon-musk
Answer any question using Elon Musk's thinking frameworks — first principles, The Algorithm, thinking in limits, and more.

**Trigger phrases:** "think like Elon," "first-principles analysis," "how would Musk see this," "Elon-style thinking"
